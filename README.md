# Wasser-Lernportal – bildbasierte Homepage

Diese Version enthält das Hintergrundbild **direkt in der `index.html` eingebettet**.
Du musst deshalb keine separate Bilddatei hochladen.

## Dateien
- `index.html`
- `style.css`
- `script.js`

Optional kannst du zusätzlich einen Ordner `pdf/` anlegen, wenn du Materialien verlinken möchtest.

## GitHub Pages
1. Die drei Dateien in dein Repository hochladen.
2. Unter **Settings → Pages**:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
3. Speichern.

Die Seite funktioniert danach direkt mit dem eingebetteten Bild.
